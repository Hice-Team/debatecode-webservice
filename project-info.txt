프로젝트 파일 안내서
====================

프로젝트: Debate Code
기준일: 2026-10-01

이 문서는 저장소의 디렉터리 경로와 파일 확장자를 조합해 프로젝트 파일에 적용할 라벨 및 역할을 정의합니다. app/처럼 파일 수가 많은 영역은 하위 경로가 기능 라벨이며, 그 안의 개별 파일명은 페이지·API·컴포넌트·유틸리티의 구체 기능을 나타냅니다. node_modules/, .git/, .next/ 등은 실행 환경 또는 생성물이라 소스 인벤토리와 분리해 설명합니다.

[프로젝트 개요]
Next.js App Router 기반의 Debate Code 서비스입니다. React와 TypeScript로 화면 및 API를 구현하고, Prisma와 PostgreSQL을 데이터 계층으로 사용합니다. 인증에는 Supabase를 사용하며, OpenNext Cloudflare 설정으로 Cloudflare Workers 배포를 지원합니다.

[라벨 범례]
APP-ROUTE: 사용자 화면, 레이아웃, 라우트별 UI
API: 서버 API 요청 처리 및 인증 콜백
UI: 재사용 화면 컴포넌트와 스타일
DOMAIN: 비즈니스 규칙, 데이터 접근, 공통 유틸리티
DATA: 스키마, 마이그레이션, 시드, 스냅샷
OPS: 배포·점검·유지보수 스크립트와 설정
DOC: 사람/에이전트용 프로젝트 설명 및 작업 지침
ASSET: 브라우저에서 제공하는 이미지·문서·기타 정적 리소스
GENERATED: 도구가 다시 생성하는 클라이언트·빌드·캐시 파일
LOCAL-ONLY: 비밀 설정 또는 개발자 로컬 상태. 공유·삭제 전에 별도 확인 필요

on-tmp/**, tmp/**, output/**, .claude/** — GENERATED/LOCAL-ONLY: 빈 임시 폴더 및 잔여 폴더로, 정리 작업을 통해 안전하게 제거되었습니다.
public/ss.ai, public/ss.psd, on-tmp-inspect.mjs — ASSET/OPS: 미사용 그래픽 원본 및 임시 진단 스크립트로, 정리 작업을 통해 제거되었습니다.
.env — LOCAL-ONLY: 로컬 비밀 설정이므로 보존했습니다.

[정리 원칙]
재생성 가능한 QA 출력과 Next.js/OpenNext 빌드 캐시만 확인 후 제거하고, 소스·설정·사용자 변경·백업·환경 변수·배포 상태는 임의 삭제하지 않습니다. 생성된 Prisma 코드와 빌드 캐시는 원본 스키마/설정이 아니라 생성물입니다. node_modules는 현재 실행 환경의 의존성이므로 보존했습니다. .wrangler는 로컬 개발 상태나 데이터가 포함될 수 있어 보존했습니다.
